# XCZS 1.0.1

本次发行包含文件标签与扫描校验修复，并更新可部署安装包。软件版本为 `1.0.1`；数据库身份继续为 `xczs-db-v1`、结构修订为 `1`，不提供历史结构迁移。

- 修复过期标签修改请求的处理，拒绝无法正确表示的扫描时间戳。
- 安装包采用已修正共享业务目录契约和实际配置校验顺序的 XSSI 实现，共享目录无需混入私有状态路径。
- 保留管理员控制、服务账号只读的配置权限，并验证已安装服务可以读取该配置且不能越权修改。
- 更新 rustls 至 `0.23.46`，处理新公布的安全公告。
- 在隔离 systemd 环境中验证实际安装、文件标签数量限制及关联错误响应，并验证服务重启后的数据保持。

发行目标为 Linux x86_64 GNU。下载归档与同一 Release 的 `SHA256SUMS`，先验证 SHA-256，再按包内安装说明操作；安装不会自动启动或启用服务。已有配置和数据必须满足当前契约，不自动转换或覆盖。
