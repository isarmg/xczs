# XCZS 1.0.4

采用唯一的固定 ROOT 安装合同：运行程序只接受 --root，安装、只读检查、初始化和离线凭据维护由独立 xssi 脚本及同源 setup 辅助程序负责。升级由脚本协调 xssc 自动停服、校验、备份、执行已实现的数据步骤、替换校验 payload、启动并验收。

移除访问者 IP、代理配置及按账号/会话累计失败限流；保留实例、文件与全局资源容量、认证及业务权限。运行检查使用 ROOT/run 单代快照，避免重复数据库复制。

只支持本次新配置、目录和数据基线，不读取旧 CLI、旧字段、旧路径或历史结构。管理员凭据使用主数据库的公共管理表，密码为 Argon2id 哈希。
