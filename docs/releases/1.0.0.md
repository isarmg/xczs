# XCZS 1.0.0

按本次明确授权重新建立发行基线：软件版本为 `1.0.0`，标签为 `v1.0.0`；当前数据库身份为 `xczs-db-v1`，结构修订为 `1`。其他自有配置、上传、API、发行清单和资源清单继续使用各自的 v1 标识。源码提交历史保留，旧 GitHub 标签、Release 和附件清除；第三方依赖与标准协议版本保持真实含义。

服务仅运行并加载已有绝对 ROOT，不包含安装、初始化、迁移或离线维护入口。独立 XSSI 安装脚本和同源 setup 辅助程序创建并检查当前配置、管理员与 SQLite 状态；升级脚本协调 XSSC 停服、检查、备份、替换当前程序并启动验收。未知结构严格拒绝，不自动转换、修改结构身份或重新初始化。

配置由管理员控制，服务账号只读；状态、运行快照和日志按最终服务沙箱授权写入。文件状态、上传进度及终态以当前 SQLite 数据为权威。启动探测使用无目录项的临时文件，管理员凭据使用公共管理表及 Argon2id 哈希。

保留登录尝试预算和文件、实例及全局容量，不识别访问者 IP。自定义访问日志中的未知请求头脱敏，可信请求标识由服务生成；公共传输警告与产品事件写入同一受管日志。TLS 测试逐次生成临时证书和私钥，仓库不保存固定测试私钥。

正式包以实际源码、同源辅助程序、完整依赖许可证和逐文件 SHA-256 验证。部署与使用见[文档入口](../README.md)。
