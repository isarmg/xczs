# xczs 1.0.3

## 更新

- 修复展开标签筛选后，在同一工作区创建、改名或删除标签，再返回文件页时仍显示旧候选的问题。标签变更会刷新候选并从候选第一页开始，不必先关闭筛选面板或重新加载页面。
- 保留文件名搜索和已选择的“全部、任一、排除”条件。刷新后无法在当前候选中识别的已选标签使用可取消选择的 `#ID` 占位，也可通过“清除标签筛选”移除；不会静默改写筛选条件。
- 补充回归，确保关闭或卸载筛选面板后的旧请求结果不会写回，刷新前的晚到响应也不能覆盖新候选。

## 数据兼容性

标签候选刷新修复不更改持久化结构。合并后的源码保留本地基准的 `xcss 1.0.7` 和对应锁文件，具体候选输入见[公共依赖](../common-support.md)。与 1.0.2 使用相同的当前数据库结构。

从更早版本升级时，仍须遵守 [1.0.2 的标签数据库兼容性说明](https://github.com/isarmg/xczs/blob/v1.0.3/docs/releases/1.0.2.md#数据兼容性升级前必读)。本版不提供旧结构迁移，不应删除或重置现有标签数据库来绕过校验。

## 验证范围

新增组件回归覆盖候选刷新、分页复位、删除已选标签、关闭与卸载清理，以及旧响应晚到。普通目录变更后的续页、递归搜索不可变快照、组合标签筛选和排序继续使用原有合同。

本地执行 Web 构建、类型与源码检查、全部 Node 单元测试，以及列表和标签的聚焦 Rust 单元与 HTTP 集成测试。完整 Rust 门禁和 Chromium/Firefox 浏览器验证仍须以本版最终提交的 CI 结果为准，本地聚焦测试不能替代完整验收。

## 下载与部署

发行资产名称为 Linux x86_64 GNU 可执行文件 `xczs-1.0.3-x86_64-unknown-linux-gnu` 和对应 `.sha256`。安装和运行步骤见[运维文档](https://github.com/isarmg/xczs/blob/v1.0.3/docs/README.md)。
