# xczs 1.0.2

## 更新

- 服务端和管理 Web 公共支撑升级到 `xcss 1.0.5`，固定同版正式发行输入。

- 标签使用不复用的递增标识，避免删除标签后，旧页面中的重命名或删除请求误作用于新标签。
- 标签重新关联区分业务冲突与数据库故障：无效源或目标仍返回冲突，数据库故障不再被错误转换为业务冲突，标签数量限制保持独立错误信息。
- 下载修改时间早于 1970 年或超出 HTTP 日期上限的文件时不再触发日期转换异常；仅省略无法表示的 Last-Modified，保留 ETag、HEAD 和字节范围下载处理。

## 数据兼容性（升级前必读）

本版的标签数据库要求 `tags.id INTEGER PRIMARY KEY AUTOINCREMENT`。已有不含该约束的旧版 `tags.db` 与本版不兼容，会在打开时被拒绝，现有数据不会被修改。

本版不提供迁移、重置或删除标签数据库的升级操作；不要将本版直接替换到依赖旧版 `tags.db` 的现有实例。保留原数据库与可用备份，继续使用与其匹配的版本，直到另行准备并验证兼容的数据处理方案。

## 验证范围

本轮源码回归已通过 68 项 Web 单元测试、20 项标签测试和 10 项下载测试。这些结果不代表浏览器或原生设备验收；最终发行版本及公共依赖更新后的检查结果应以对应提交的 CI 为准。
